# C公益共享创作画布

本轮按2026-11-28最新确认改版，覆盖《C公益_AI内容工作台_PRD_首次提交评审版_20261120.md》中画布、事实引用、可编辑源稿与版本保留规则；角色和主流程以最新用户决策为准。原型执行说明中的旧版新媒体交接/审批主线不再适用于本轮。

## 打开

直接用浏览器打开同目录 `C公益交互原型.html`。CSS、脚本和模板图均在文件内，无安装步骤、外部字体或 CDN。

源码在 `dist/`，原生HTML/CSS/JS，无新增依赖。运行 `node build.cjs` 生成目标单文件；`node --test model.test.cjs` 运行18项领域测试。开发预览：`python3 -m http.server 8765 --bind 127.0.0.1`，访问 http://127.0.0.1:8765/C公益交互原型.html 。

## 验收路径

1. 首屏包含排期、主题、方案、公众号、小红书五张可编辑卡片，内置示例内容。
2. 直接打开小红书修改标题和配图，或先编辑任意其他卡片。点击卡片、编辑按钮或顶部名称均可进入。
3. 返回排期修改地点，再打开主题或方案。生成与手写可独立使用，确认动作只记录当前版本。
4. 方案更新后平台稿保留手改内容，可以明确选择按新方案更新或沿用。
5. 当前成员可以直接定稿。本机操作默认署名“我”，历史署名保留。
6. 拖动节点标题栏移动；空白处拖动平移；按钮或Ctrl/⌘+滚轮缩放；回到全图。刷新后内容、版本、位置和缩放均保留。
7. 评论可指定标题、正文或配图并@同事；定位按钮打开对应编辑字段。成员面板列出本地示例。
8. 修改并采用上游方案，平台稿仅提示“方案已更新”。可明确更新（先保留旧稿），或沿用原方案，不静默覆盖。

## 模拟与存储边界

- 方案、文案、图像为确定性的本地模板生成，不调用真实模型；任意主题会带入方案与平台标题，不代表智能策划能力。
- 三名成员和@为署名及讨论演示，没有真实多人同步或通知；无飞书接入、部门权限服务或自动发布。
- 图片是可编辑的模板图，明确不作为真实现场证据；可以上传本机背景图，须补充来源并确认使用状态。
- 新版使用 `cgy-shared-canvas-v2` 本地状态，保留旧版存储。不同浏览器、文件入口及线上域名不共享演示状态。
- 多窗口出现更新会停止覆盖并提示先导出本页副本。存储被禁用或空间不足时仅本页保留，关闭后无法恢复未写入本机的变化。

独立功能代码复核发现并修复上传图片重复快照导致的容量风险：图片只存一份、版本用引用，未引用旧图回收；上传无法写入本机时回滚，拒绝替换并保留原稿。完整Impeccable独立视觉签收仍缺可交付的桌面/窄屏截图，不能作为已通过视觉门槛声称。
