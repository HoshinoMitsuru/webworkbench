# C公益 Demo 打样汇总报告

G04 内容生产方向｜2026-11-19

**目的**：基于现有调研（机构画像、小红书增长点、官网调研）预猜机构需求，做出可操作原型，供对谈验证，非承诺交付。

**四个打样**

1. **D1 攒劲内容工坊**（主推，候选A）：活动当天填一行归档（沿用十月刊格式），一键生成五路产物——公众号回顾、小红书青年故事/活动反馈/公益科普、海报文案。未授权素材自动拦截；数字日期锁定事实；产物须人工过审。命中P1–P4、P9。
2. **D2 月报工坊**（二期形态，候选B）：台账进、月报出。全部数字由台账计算并自动勾稽，模板不产新数字；金额与备案号留人工复核；空月不编数据。命中P6/P7。
3. **D3 青桥进度信**（低成本扩展）：报名/排队/匹配三态各一封变量通知，补上匹配等待期内容空白。对应P8假设（外部类推，待访谈验证）。
4. **攒劲校准引擎**（流量监测适配）：复制自黑客松校准引擎，护栏零改动、只换业务层——四号账号矩阵＋G1–G7公益规则（产能缺口、素材复用、等待期失联、合规红线拦截等）。D1–D3是「手」，它是「眼睛」：每月跑一轮，校准卡指回各工具功能位，形成闭环。

**验证**：三个网页Demo经浏览器实测（核心路径、必填校验、授权拦截、空态恢复、390/1280px布局），截图存demo/qa/；引擎定向评测44/44通过，护栏与原45条基线零改动，源目录零写入。

**边界**：生成均为本地模板模拟，数据全部虚构并已标注；引擎阈值（30%成文率、50%三类占比、14天等待）为预研假设；真实生成质量需机构语料约束，待对谈校准。

**下一步**：对谈先问后演——D1走完整链路、D2问台账意愿、D3验证P8；收尾逼优先级：「四周只做一个，选哪个？」
