## 三、使用顺序

1. 先读 `00`，把 A 段 + B 段整段贴进每个 Agent 的系统提示词末尾；
2. 再按内容类型取 `02`（文案）/ `03`（视觉）/ `04`（视频）里的对应 Prompt；
3. 派单与终审用 `06`，逐条质检用 `07`；
4. 需要看示例与对接话术看 `08`；改完规则要回归验证用 `09`。

## 四、验收自查（5 分钟可核）

- [ ] 搜「C 公益」，应只剩错误示例行；正文里品牌名都是 `C公益` 且 C 前有空格。
- [ ] 搜「#C公益」，微信话术中标签后有一个空格。
- [ ] 任取一篇公众号产出，标题 ≤34 字、摘要 ≤52 字、文末有五行署名。
- [ ] 任取一份视觉产出，写明「透明底 ® 标 LOGO + 位置 + 保护空间」，且没有自拟十六进制色值。
- [ ] 搜「青桥计划 -」，应为 0 处（正确写法是半角横杠、前后不加空格的 `青桥计划-对话吧` 等）。

## 五、仍需机构确认的 5 项（不影响测试放行，影响正式出图）

- 品牌色十六进制色值 / Pantone 编号
- 机构可商用字体清单与授权范围
- LOGO 源文件（透明底 ® 版 / 泛白版 / 横竖版）
- 可画品牌工具箱链接与常用模板最新版
- 标准横版 LOGO 配套介绍话术原文

确认后直接回填 `00` 的 F 段与 `03`、`07` 两处，不需要改 19 个 Prompt 结构。
