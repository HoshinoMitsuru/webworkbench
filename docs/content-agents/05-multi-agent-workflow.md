## v4 规范层（第一顺位约束，依两份机构规范）

> 本节优先于本文其余任何表述；条款来源与判定方法见《00 品牌与文案规范落地手册》。

1. 品牌名唯一写法 `C公益`：C 大写、C 前空一格、C 与「公益」之间不空格；C 前紧跟中文标点或位于行首时不空格。禁 `c公益`、`C 公益`、`关注C公益`。
2. 官方唯二名称：`C公益` 或 `宁夏青年发展公益慈善中心（品牌名：C公益）`，禁只写机构名不露品牌。
3. 数字与前后中文之间加空格（数字在行首、或紧跟中文标点时不加）。
4. 全中文标点，引号用「」『 』；不加粗整段，重点加粗每篇 ≤3 处。
5. 未定内容写【斜体黄色｜待补充：XXX】，禁裸写【待补充】、禁编造。
6. 素材只用授权 / 可商用，文末逐行署名：`图片 | C公益 pexels` `音乐 | 周杰伦 - xxxx` `视频 | C公益` `文案 | XXX` `排版 | XXX`。
7. 标签品牌词 `#C公益`；微信单 # 后空一格，微博双 # 前后补空格。
8. 项目全称：青桥计划-对话吧 / 青桥计划-疑惑当铺 / 青桥计划-职业规划训练营 / 探索者行动（半角横杠、前后不加空格）。

**流程追加**：D-01 派单前先过「规范前置校验」（品牌名三要素、标签平台规则、公众号字数、LOGO 类型），不合格不派单；质检增加规范回归环节。

## 一、总体架构：一个总编 + 三条产线 + 一个质检

```
                          ┌───────────────────────────┐
                          │   D-01 总编调度 Agent        │
                          │  登记 → 分派 → 卡点 → 终审 → 回流 │
                          └─────────────┬─────────────┘
        ┌───────────────────────────────┼───────────────────────────────┐
        ▼                               ▼                               ▼
┌──────────────────┐        ┌──────────────────┐        ┌──────────────────┐
│  文案线（A 类 12） │        │ 视觉线（B 类 6）   │        │ 视频线（C 类 1）  │
│                  │        │                  │        │                  │
│ 小红书 A-01/A-02  │        │ B-01 海报         │        │ C-01 短视频脚本   │
│ 公众号 A-03/04/05 │        │ B-02 小红书封面    │        │  ≤60 秒四类       │
│ 通用   A-06~A-12  │        │ B-03 多图笔记      │        │  分镜 + 发布包    │
│                  │        │ B-04 公众号封面配图 │        │                  │
│                  │        │ B-05 PPT/报告      │        │                  │
│                  │        │ B-06 其他物料      │        │                  │
└────────┬─────────┘        └────────┬─────────┘        └────────┬─────────┘
         │  文案成稿 / 设计稿 / 脚本                                │
         └───────────────────────────┼───────────────────────────────┘
                                     ▼
                          ┌───────────────────────────┐
                          │   D-02 质检 Agent           │
                          │  A 通用 + B 账号 + C 视觉    │
                          │  + D 通用体裁 + E 视频       │
                          └───────────────────────────┘
```

- **D-01 总编**：不写稿、不做图、不剪片，只做选题登记、按类分派、排期、终审、规则回流。
- **A 类 12 个**：小红书 2 个账号、公众号 3 个账号、通用体裁 7 个；各自只吃自己那份 Prompt，不跨号代写。
- **B 类 6 个**：海报、小红书封面、小红书多图、公众号封面与配图、PPT 与报告模板、其他物料；只做视觉组织，不改事实。
- **C 类 1 个**：短视频脚本，四类模板 + 分镜 + 发布包；不出成片。
- **D-02 质检**：独立于三条线，拿成稿 / 设计稿 / 脚本对照清单判「通过 / 打回」，不改稿。

> 关键原则不变：**撰稿、设计 / 脚本、质检必须是分开的角色**。自己写自己审会漏错；质检独立跑一遍，才复现「贴稿 → 逐条挑错」的收敛过程。视觉稿与脚本同样要过质检。

## 二、三条产线

### 2.1 文案线（六步，沿用 v2）

1. **登记（D-01）**：选题、素材来源、内容类型、子类（平台 / 账号 / 通用体裁）、受众版本、活动阶段、截止时间、待补清单。素材里没有的事实一律登记为待补。
2. **撰稿（A 类）**：只喂该 Agent Prompt + 原始素材，产出标题、正文、标签、配图建议。
3. **独立质检（D-02）**：按 A 通用 + B 对应账号段逐条过，输出通过 / 打回。
4. **打回修改（A 类）**：按违规条号整段重写，不局部打补丁；改完回质检，直到全绿。
5. **终审（D-01）**：核事实、待补、品牌与项目名、配图版权、排期。
6. **发布 + 回流**：记录反复出现的新问题，属规则的经人工确认写进 Prompt。

### 2.2 视觉线（四步，沿用 v2 并细分）

1. **派单（D-01）**：把质检通过的文案定稿 + 品牌规范 + 授权素材交给对应 B 类 Agent，明确物料类型（B-01 哪一版 / B-02 / B-03 几张 / B-04 / B-05 哪类 / B-06 哪一项）。
2. **设计（B 类）**：按视觉共用规范出版式、分区逐字文案、版权标注、可编辑性说明；待补占位，不新增事实。
3. **独立质检（D-02）**：按 C 段核查品牌规范、规格比例、信息一致、素材版权、待补占位、安全边距、导出标注。
4. **终审交付（D-01）**：核 Logo / 配色 / 授权 / 待补，通过后交人工补二维码、实拍授权、字体确认，高清导出。

> 视觉线的起点可以是文案定稿，也可以是「文案未定、先出视觉方向」。后者必须标「待文案确认」，定稿出来后回填文字再复检。

### 2.3 视频线（四步，v3 新增）

1. **派单（D-01）**：给 C-01 素材（活动方案 / 访谈 / 科普主稿）+ 类型（招募 / 回顾 / 故事 / 科普）+ 目标平台 + 时长上限。
2. **出稿（C-01）**：主题一句话 → 四段结构 → 分镜表 → 素材清单 → 发布包 → 选题推荐。
3. **独立质检（D-02）**：按 A 通用 + E 视频段核查事实、时长、字幕、授权、平台合规。
4. **终审交付（D-01）**：核素材授权、人物授权、政策来源、发布包；通过后交人工拍摄 / 剪辑，成片另走人工审片。

> 视频与文案的关系：短视频脚本优先复用已通过质检的文案事实（A-03 故事、A-05 招募、A-08 科普），避免同一活动两套说法；视频脚本不反向改写文案。

### 2.4 三条线怎么配合

| 场景 | 走线顺序 |
|---|---|
| 一次活动全量分发 | 文案线先出主文（A-04/A-05）→ 质检 → 视觉线出海报 / 封面 / 多图 → 视频线出招募短片 → 各自质检 → 统一终审排期 |
| 只要一张海报 | 直接走视觉线（B-01），文字以现有定稿为准；无定稿则先走文案线一步 |
| 只要一条短视频 | 直接走视频线；事实取自已有定稿或素材 |
| 长线栏目（科普） | A-08 出主稿与来源核验 → A-01/A-02 改写 → C-01 出视频 → B-06 出科普长图 |
| 同一资料多受众 | A-06 出学生 / 公众两版 → A-11 出通稿 → 分别配 B-01 海报与 C-01 短片 |

### 3.2 视觉路由

| 物料信号 | 分派到 | 物料 |
|---|---|---|
| 招募 / 活动预热、正式、倒计时、回顾海报 | B-01 | 3:4 四版本 |
| 只做一张小红书封面 | B-02 | 单张封面 |
| 一篇笔记要配 5-7 张成套图 | B-03 | 多图拆页 |
| 公众号推文头图 + 文内配图 | B-04 | 2.35:1 首图 + 1:1 次图 + 配图位 |
| 活动现场 / 培训 / 汇报 / 合作 / 成果报告 | B-05 | 五类 PPT 与报告模板 |
| 朋友圈长图 / 科普长图 / 人物卡 / 日程图 / 邀请函 / 数据成果图 / 简讯海报 / 社群通知图 | B-06 | 八类物料 |

判定要点：**封面与多图分开派**——只要封面走 B-02，成套笔记走 B-03（B-03 内部调用 B-02 的封面结论，避免两套封面）；公众号的封面与内文配图必须同一 Agent（B-04），防止首图与正文两张皮。

### 3.3 视频路由

| 需求信号 | 分派到 | 类型 |
|---|---|---|
| 活动招募短视频、岗位预告 | C-01 | 招募类（15-45s） |
| 活动结束剪辑、现场回顾 | C-01 | 回顾类（20-50s） |
| 参与者 / 受益人故事 | C-01 | 故事类（30-60s） |
| 职业规划 / 求职 / 政策科普 | C-01 | 科普类（30-60s） |
| 视频号 / 抖音标题、简介、发布说明、话题 | C-01 | 发布包（随脚本出） |
| 需要成片 | C-01（脚本）+ 人工 / 工具链（拍摄剪辑） | 成片不在 Agent 范围 |

### 3.4 跨形态组合原则（沿用 v2 并扩到三条线）

- **一条素材多平台分发**：不复制粘贴。同一项目可同时出「A-04 长文 + A-01 共鸣笔记 + A-02 招募笔记 + B-01 海报 + C-01 短片」，每件各自派单、各自走红线、分别登记编号。
- **文案先行、视觉与视频跟进**：常规顺序是文案定稿质检通过后，再排版与拍片；画面文字与字幕以定稿为准。
- **判断不了的选题**：挂「待归类」，不硬塞；素材事实不全的，标缺料，不进生产。
- **跨类不代做**：文案 Agent 不写分镜，视觉 Agent 不改正文，视频 Agent 不改文案事实。

## 四、共用层与分层维护

| 层级 | 内容 | 改动规则 |
|---|---|---|
| 共用层（总览第 0 节） | 机构口径、品牌名、共用禁区、待补格式、视觉规范 | 变化时改一次，19 个 Agent 同步 |
| 账号层（A-01~A-05） | 各账号红线、文体、输出结构 | 只在该账号反复踩同一类问题时增补，不跨号搬规则 |
| 通用体裁层（A-06~A-12） | 三受众、阶段、科普、社群、朋友圈、通稿、公益传播 | 按体裁独立维护；账号规则作为附加约束，不写进通用层 |
| 视觉层（B-01~B-06） | 共用视觉规范 + 各物料规格 | 品牌配色、字体库、模板更新只改视觉层 |
| 视频层（C-01） | 时长预算、四类模板、分镜字段、平台包 | 平台规则变化（时长 / 字数）时只改视频层 |

**规则回流判断标准**（不变）：同一类问题在 ≥2 篇 / 2 件里重复出现 → 提炼成规则，写进对应 Agent；只出现一次、属本次措辞偏好 → 人工微调，不进 Prompt，避免规则膨胀。

## 五、质检接口

- 派单给 D-02 时必须带三样：**类型**（文案 / 视觉 / 视频）、**具体 Agent 编号**、**成稿全文**。
- 质检输出固定：类型 + 编号 + A 通用逐条 + 专属段逐条 + 结论 + 打回项（条号 + 位置 + 原文 + 问题 + 改法）。
- 总编不替质检下结论，也不删改打回条号；打回项原样转回原 Agent。
- 清单分工：A 段全类型通用；B1-B5 对 5 个账号；C 段对 6 个视觉 Agent；D 段对 7 个通用体裁；E 段对视频。

（完整清单见《07 质检 Agent 系统提示词与结构化质检清单 v3》。）

## 六、排期与协作节奏

- **选题周会（总编 + 人工）**：登记下周选题，判定内容类型，分派到 A / B / C，标注素材是否齐全、需不需要多受众版本、配套视觉与视频。
- **每件至少一轮独立质检**；打回后必须复检，不允许自判通过。
- **人工补齐待补项**：所有【待补充】必须由人工在发布前填实；视觉的二维码、实拍授权、字体授权由人工确认；视频的人物授权、场地、政策来源由人工确认。
- **复盘节点**：每发完一批（建议 5-8 件），总编汇总新踩问题，决定哪些进 Prompt / 视觉规范 / 视频模板，哪些留人工。
- **三条线的产能建议**：一次活动标准包 = 1 篇主文 + 1 条笔记 + 1 套海报 + 1 条短片 + 1 组群话术；按此估算一周可承接的活动数，避免同时开三条线导致质检排队。

## 七、边界与待办

1. 主号月报 / 报告 / 指南与活动回顾文体尚未单独实测，首篇重点盯事实陈述与无旁白。
2. A-06 三受众、A-07 阶段、A-08 科普、A-11 通稿、A-12 公益传播为本版新立 Prompt，待首篇实测。
3. B-01~B-06 的实际出图能力依赖设计工具 / 模板库，本版先固化规范与交付格式。
4. C-01 未实测，建议先跑 30 秒招募 + 45 秒科普各一条，验证时长预算。
5. 小红书 8 条被拦截笔记未取全文，配图封面需人工核对。
6. 同一机构口径如官网更新（场次 / 人次 / 资质），由总编统一改共用层并同步 19 个 Agent。
7. 数据看板、投放追踪、自动剪辑不在本流程内。

## 八、质检清单实测记录（v2 原文保留，2026-11-27）

> 目的：验证结构化质检清单（A1-A13 通用 + B1-B5 专属）能否独立抓出埋雷。方法：模拟撰稿 Agent 交稿，故意埋雷，再由质检 Agent 按清单逐条判定。
