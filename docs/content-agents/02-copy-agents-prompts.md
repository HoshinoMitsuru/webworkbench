## v4 规范层（第一顺位约束，依两份机构规范）

> 本节优先于本文其余任何表述；条款来源与判定方法见《00 品牌与文案规范落地手册》。

1. 品牌名唯一写法 `C公益`：C 大写、C 前空一格、C 与「公益」之间不空格；C 前紧跟中文标点或位于行首时不空格。禁 `c公益`、`C 公益`、`关注C公益`。
2. 官方唯二名称：`C公益` 或 `宁夏青年发展公益慈善中心（品牌名：C公益）`，禁只写机构名不露品牌。
3. 数字与前后中文之间加空格（数字在行首、或紧跟中文标点时不加）。
4. 全中文标点，引号用「」『 』；不加粗整段，重点加粗每篇 ≤3 处。
5. 未定内容写【斜体黄色｜待补充：XXX】，禁裸写【待补充】、禁编造。
6. 素材只用授权 / 可商用，文末逐行署名：`图片 | C公益 pexels` `音乐 | 周杰伦 - xxxx` `视频 | C公益` `文案 | XXX` `排版 | XXX`。
7. 标签品牌词 `#C公益`；微信单 # 后空一格，微博双 # 前后补空格。
8. 项目全称：青桥计划-对话吧 / 青桥计划-疑惑当铺 / 青桥计划-职业规划训练营 / 探索者行动（半角横杠、前后不加空格）。

**文案类追加硬约束**：公众号标题 ≤ 34 字（含标点）、摘要 ≤ 52 字（15 字左右最佳）；社群 / 朋友圈话术不超过手机屏幕 2/3，过长必须分割；标签须代入语句，不孤立成串；涉及新闻与热点必须援引官方媒体或权威机构并注明来源。

## 使用说明

| 项 | 说明 |
|---|---|
| 粘贴方式 | 每个 Agent 的 Prompt 在代码块内，整段复制为该 Agent 的 system prompt |

| 招募前（预热） | 抛主题、造期待 | 痛点 / 悬念 / 背景，不放完整参数 | 不提前承诺名额结果 |
| 正式招募 | 讲清是什么、谁能来、怎么报 | 项目介绍 + 参与对象 + 报名方式 + 待补参数占位 | 走招募红线，不硬叫卖 |
| 招募期间 | 提醒 + 答疑 + 补强 | 常见疑问、价值重申、（待补）截止提醒 | 不写「最后 X 名额 / 错过后悔」 |
| 活动前 | 行前告知 | 时间地点集合、准备事项、须知 | 参数以官方为准，缺则占位 |
| 现场 | 记录 / 即时播报 | 客观场景、授权画面配文，简短 | 不编感想、不摆拍叙事 |
| 结束（回顾） | 沉淀成果 | 客观数据 + 授权照片 + 参与者反馈（须素材真实） | 不虚构获奖 / 改变命运 |
| 后续 | 长尾传播 / 致谢 / 转化 | 致谢、后续入口、系列预告 | 不重复硬广 |

【写作规则】
- 一次只写一个阶段；若要求"整套组合"，逐阶段成篇并标注阶段名，不合并成一篇长文。
- 每篇必须明确"本篇属于哪个阶段"，并只放该阶段该有的信息：预热不放报名二维码与完整参数；行前告知不重复招募卖点；回顾不写"快来报名"。

- 结尾行动点按阶段给：预热=留期待 / 订阅；正式招募=报名入口；招募期间=答疑入口；活动前=集合信息；现场=关注后续；回顾=成果与感谢；后续=下一个入口。
