# C公益 v4 · 00 品牌与文案规范落地手册

> 本文件是 v4 全部 19 个内容 Agent 的**第一顺位约束层**：任何 Prompt、任何质检清单、任何跑批样例与本文冲突时，以本文为准。
> 依据两份机构规范原文：《C公益文案撰写规范》《C公益品牌视觉对外露出使用规范——"我们的形象如何呈现"》。
> 用法：新建任一 Agent 时，把本文 A 段（文字）+ B 段（视觉）**整段粘贴进系统提示词末尾**，再叠加该 Agent 的专属 Prompt。

---

## 0. 为什么要有这一版

v3 的 19 个 Agent 结构、分工、跑批都成立，但把品牌名写成了「C 公益」（C 与"公益"之间带空格），并把标签写成 `#C 公益`，与机构规范相反；公众号标题/摘要字数、素材署名格式、Logo 位置与最小保护空间、品牌色优先级等条款也没有落到 Prompt 里。机构验收反馈正是这几处。v4 不是打补丁，而是把两份规范逐条转成可执行条款，重新贯穿到全部 Prompt、质检清单与样例。

## A. 文字规范（19 个 Agent 通用，逐条可判定）

### A-1 品牌名书写（最高频错误，单独成条）

| 项 | 规则 |
|---|---|
| 正确写法 | `C公益`：字母 C 必须**大写**；C **前面空一格**；C 与「公益」**之间不空格** |
| 句中示例 | 「欢迎关注 C公益」「这是 C公益在第 7 期做的尝试」 |
| 不空格的情形 | C 位于行首、或 C 前紧跟中文标点（。、，；：！？「」『』（）《》—…）时，不再加空格 |
| 错误写法 ❌ | `c公益`（C 未大写）、`C 公益`（C 与公益之间加了空格）、`关注C公益`（C 前缺空格） |
| 官方唯二名称 | ① `C公益`　② `宁夏青年发展公益慈善中心（品牌名：C公益）`——对外介绍机构时必须二选一，不得只写「宁夏青年发展公益慈善中心」而不露品牌名，也不得写成「宁夏青年发展公益慈善中心（C公益）」（漏"品牌名"三字） |
| 例外 | 政府材料、合同等正式文件除外 |
| 自动化检查 | 正则 `(?<![　 、。，；：！？「」『』（）《》—…\s])C公益` 命中即为「C 前缺空格」；`C 公益` 命中即为「C 与公益间多空格」；`c公益` 命中即为「未大写」 |

> 注：Markdown / 富文本渲染时，C 前的那一格就是普通半角空格，不要用全角空格、不要用不换行空格。

### A-2 数字与中文之间空格
数字前后凡紧邻中文，加空格：「在 4 月 1 日」「620 余场」「13 年」「6 万余人次」「32 名学生」。
数字在行首、或数字前紧跟中文标点时，不再加空格。

### A-3 标点
全中文标点；引号用「」『 』；不用英文直引号 `" "`、不用半角逗号句号；书名号《》、括号（）用全角。

### A-4 重点标注
重要必读信息用**加粗**；禁止整段加粗（重点太多＝没有重点），每篇加粗不超过 3 处、每处不超过 1 句。

### A-5 待补占位
未确定内容一律 `【斜体黄色｜待补充：XXX】`，禁止裸写【待补充】，禁止编造、禁止臆测「完全免费」。

### A-6 原创与版权
全文原创，严禁抄袭；字体、图片、表情包、音乐**只用授权或明确可商用**素材，禁用来源不明（网络随手搜）素材。

### A-7 素材与作者署名（v3 缺失项，全部产出必须带）
文章 / 笔记末尾按下列格式逐行署名，多个来源用空格隔开：

```
图片 | C公益 pexels
音乐 | 周杰伦 - xxxx
视频 | C公益
文案 | XXX
排版 | XXX
```

- 无该项则省略该行，不要写「无」。
- 感性文字（受益人故事、活动回顾）作者可用艺名 / 花名；理性文字（评估报告、数据复盘）必须用真实姓名。
- 素材来自机构实拍时写 `图片 | C公益`；来自可商用图库时写 `图片 | C公益 pexels` 这类「机构 + 图库」格式。

### A-8 公众号文章标题与摘要（硬字数）
- 标题 ≤ **34 字**（含标点、含数字，含「C公益」）。
- 摘要 ≤ **52 字**，**15 字左右最佳**（摘要同时用于转发会话时的小字提示）。
- 标题要给吸引力，但禁标题党、禁夸大承诺、禁「震惊」「速看」「最后 X 个名额」。

### A-9 公众号内容合规
- 不得传播谣言；涉及新闻与热点必须援引官方媒体或权威机构信息，并在文中或文末注明来源渠道。
- 内容须符合法律法规与社会主义核心价值观；涉及民族、宗教、地域表述保持中性、尊重，不制造对立，不涉及领土与主权的不当表述。
- 涉及未成年人、受益人故事，须取得授权并做去标识化处理（姓名、学校、住址、可识别影像）。

### A-10 社群 / 朋友圈话术
- 必须给到转发话术，目的：一句话说清是什么活动、指引打开海报或推文。
- 长度不超过手机屏幕的 2/3；不可避免过长时用换行或分割线断开。
- 标签直接代入语句中，不堆在末尾孤立成串。

### A-11 话题标签体系（v3 写错项，单独成条）

**机构可用标签（官方清单，写法照抄）**：`C公益`、`沙鸣Talks`、`沙鸣`、`沙鸣Explore`、`青桥计划-对话吧`、`青桥计划-疑惑当铺`、`青桥计划-职业规划训练营`、`大学生创造力夏令营`、`探索者行动`。
**灵活标签**：职业规划、银川、大学生、实习、公益 等，视平台该类标签的讨论活跃度决定是否使用。

| 平台 | 规则 | 示例 |
|---|---|---|
| 微信（公众号 / 朋友圈 / 社群） | **单 #**，标签写完后**空一格**再接正文 | `#C公益 第 7 期一日职业体验开放报名` |
| 微博 | **双 #**，标签文字前后补空格 | `#C公益# 第 7 期一日职业体验开放报名` |
| 小红书 | 单 #，标签区独立成段，8-11 个 | `#C公益 #一日职业体验 #银川` |
| 抖音 | 单 #，3-5 个，正文内嵌 | `#C公益 #职业体验` |

- 标签品牌词必须写 `#C公益`（C 与公益之间不空格），禁 `#C 公益`、`#c公益`。
- 鼓励多标签：任何有持续传播价值的词都可做标签，但须与内容真实相关。

## B. 视觉规范（B 类与 C 类 Agent 必守）

### B-1 品牌体系与名称
机构四大品牌：**C公益**（主品牌）、**攒劲青年**、**志夏青年 Just Shine**、**沙鸣 Talks**。
- 对外一律用全称，「攒劲青年」**不可简称「攒劲」**；「沙鸣 Talks」中 Talks 首字母大写、T 与 alks 之间不空格，Talks 前空一格。
- 各品牌视觉资产以「可画（Canva）品牌工具箱」中对应工具箱为准（C公益 / 攒劲青年 / 志夏青年 / 沙鸣 Talks），不自行重绘、不自行调色。

### B-2 品牌色（AIGC 出图优先级最高的一条）
品牌 LOGO 与视觉系统由三色构成，含义即用色逻辑：

| 色 | 含义 | 用法 |
|---|---|---|
| 橙 | 扎根西北（土地） | 主视觉底色、标题块、行动按钮；海报占比 30%-45% |
| 蓝 | 连接资源与青年（水） | 信息区、图形线、辅助块；与橙形成主对比 |
| 绿（嫩芽） | 向上生长（青年） | 点缀：嫩芽图形、进度点、成功态；占比 ≤15% |
| C 型环绕 | 改变持续发生 | 作为版式骨架（C 形弧线、环绕动线），不做无意义装饰 |

**出图规则**：一切配图 / 封面 / 海报 / PPT 主色**优先取品牌橙、蓝、绿**；中性底色用米白 / 暖灰承托；禁高饱和荧光色、禁紫粉电商风、禁与品牌色冲突的渐变。
**色值**：以品牌工具箱 / VI 源文件为准（本手册不写死十六进制）。制作前先从可画品牌工具箱取色，取不到则标 `【斜体黄色｜待补充：品牌色值】`，不得自拟色值交付。

### B-3 LOGO 使用
- 默认用**彩色 LOGO**；泛白底版**仅**用于报纸、广告等单色印刷场景。
- 海报用**透明底带 ® 标的 LOGO**；位置：顶部居中 / 左上角 / 右上角三选一，全机构统一。
- 单 LOGO 时横版、竖版均可；多 LOGO 时按合作方 LOGO 比例选横版或竖版，**全部横向排列**，`C公益` 在前、合作方在后，之间保持间隔，任何 LOGO 不得裁边、不得压字。
- **最小保护空间**：LOGO 四周留白区不得出现任何文字、符号、图形。
- 公众号推文介绍机构时用**标准横版 LOGO + 标准话术**，LOGO 宽度不超过文字段落宽。
- PPT 正文页 LOGO 放**右上角**（横版）。
- 线上账号头像用**竖版 LOGO**（攒劲青年账号同理）。
- 周边：徽章用竖版，KT 板用横版。

### B-4 版式与物料
- 海报 3:4，留白 ≥ 8mm，二维码边长 ≥ 18% 短边，不得压字压图。
- 公众号首图 2.35:1，次图 1:1；小红书封面 3:4；多图 5-7 张。
- 图内文字只用机构可商用字体（默认思源黑体 / 思源宋体，商用授权范围内）。
- 常用模板统一取「C公益常用模板」，模板不定期更新，出图前先取最新版。

## D. 质检新增条目（并入 07 的 A 段与 B 段）

| 编号 | 检查动作 | 通过标准 | 违规示例 ❌ |
|---|---|---|---|
| A14 | 品牌名三要素 | C 大写、C 前有空格、C 与公益无空格 | `c公益`、`C 公益`、`关注C公益` |
| A15 | 官方唯二名称 | 用 `C公益` 或 `宁夏青年发展公益慈善中心（品牌名：C公益）` | 只写机构名不露品牌、写成「（C公益）」 |

| A17 | 素材与作者署名 | 末尾有 `图片 / 音乐 / 视频 / 文案 / 排版` 行，格式对 | 无署名、写「来源网络」 |
| A18 | 标签平台规则 | 微信单 # 后空一格；微博双 # 前后空格；含 `#C公益` | `#C 公益`、微信里 `#C公益正文`无空格 |

| B20 | LOGO 类型与位置 | 海报透明底 ® 标；PPT 右上角；账号头像竖版；泛白版仅单色印刷 | 海报用泛白版、LOGO 压字裁边 |

| B22 | 品牌色优先 | 主色取品牌橙 / 蓝 / 绿，占比合规，无色值自拟 | 荧光紫、粉蓝电商色、自编 hex |
| B23 | 多 LOGO 排列 | 横向、C公益在前、间隔均匀、无裁边 | 竖排、合作方在前、LOGO 裁半边 |
