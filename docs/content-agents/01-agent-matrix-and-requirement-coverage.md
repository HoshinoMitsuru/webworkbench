## v4 规范层（第一顺位约束，依两份机构规范）

> 本节优先于本文其余任何表述；条款来源与判定方法见《00 品牌与文案规范落地手册》。

1. 品牌名唯一写法 `C公益`：C 大写、C 前空一格、C 与「公益」之间不空格；C 前紧跟中文标点或位于行首时不空格。禁 `c公益`、`C 公益`、`关注C公益`。
2. 官方唯二名称：`C公益` 或 `宁夏青年发展公益慈善中心（品牌名：C公益）`，禁只写机构名不露品牌。
3. 数字与前后中文之间加空格（数字在行首、或紧跟中文标点时不加）。
4. 全中文标点，引号用「」『 』；不加粗整段，重点加粗每篇 ≤3 处。
5. 未定内容写【斜体黄色｜待补充：XXX】，禁裸写【待补充】、禁编造。
6. 素材只用授权 / 可商用，文末逐行署名：`图片 | C公益 pexels` `音乐 | 周杰伦 - xxxx` `视频 | C公益` `文案 | XXX` `排版 | XXX`。
7. 标签品牌词 `#C公益`；微信单 # 后空一格，微博双 # 前后补空格。
8. 项目全称：青桥计划-对话吧 / 青桥计划-疑惑当铺 / 青桥计划-职业规划训练营 / 探索者行动（半角横杠、前后不加空格）。

本文第一节的分类树、第三节的 19 Agent 总表、第六节共用层均按 v4 规范层复核；共用层新增「0.7 品牌与文字规范」「0.8 视觉规范」两小节。

## 一、为什么重排：v2 与 v3 的结构差异

| 维度 | v2（第一轮） | v3（本版） |
|---|---|---|
| 分类依据 | 按平台 / 角色：5 个文案账号 + 1 个视觉 Agent + 总编 + 质检 | 按内容类型：文案类 / 图文视觉创作类 / 视频脚本类，其下再按平台、账号、物料细分 |
| 视觉能力 | 1 个「图文与视觉设计 Agent」打包海报 / 多图 / PPT / 其他物料 | 拆成 6 个独立 Agent：海报、小红书封面、小红书多图、公众号封面与配图、PPT 与报告模板、其他物料 |
| 通用体裁 | 挂在「第三部分 通用文案扩展模块」，不是独立角色 | 提为 7 个独立 Agent：三受众、活动阶段、科普、社群、朋友圈、新闻稿、公益传播 |
| 视频 | 明确「本轮不建」 | 独立为视频脚本类 Agent（C-01） |
| 账号归属 | 平铺 5 个账号 | 先分平台（小红书 / 公众号），平台下再分账号 |
| 内容保留 | — | v2 全部正文按「原文照搬 / 拆分 / 扩写」三类处理，去向逐条登记（见第五节） |

一句话：**分类骨架换成需求的，血肉还是第一轮那套。**

## 二、v3 分类树

```
C公益内容生产 Agent 体系（19 个内容 Agent + 2 个支撑角色）
│
├─ 一、文案类 Agent（A，12 个）
│   ├─ 1. 小红书
│   │   ├─ A-01 「来自西北的小C同学」机构号
│   │   └─ A-02 「来自西北的攒劲青年」活动号
│   ├─ 2. 公众号
│   │   ├─ A-03 主号（受益人故事 / 活动回顾 / 月报报告指南）
│   │   ├─ A-04 「C公益活动种草中心」
│   │   └─ A-05 「攒劲青年」招募号
│   └─ 3. 跨平台通用体裁（不属于单一账号，按内容目的调用）
│       ├─ A-06 三受众版本（学生版 / 公众版）
│       ├─ A-07 活动阶段文案（预热 → 后续 7 阶段）
│       ├─ A-08 青年科普栏目（6 个栏目方向）
│       ├─ A-09 社群话术（微信群 / 私域）
│       ├─ A-10 朋友圈文案
│       ├─ A-11 新闻通稿
│       └─ A-12 公益传播文案（机构成果 / 项目价值 / 支持者反馈）
│
├─ 二、图文视觉创作类 Agent（B，6 个）
│   ├─ B-01 活动海报（3:4，预热 / 正式招募 / 倒计时 / 回顾）
│   ├─ B-02 小红书封面
│   ├─ B-03 小红书多图笔记（5-7 张成套拆页）
│   ├─ B-04 公众号封面与配图
│   ├─ B-05 PPT 与报告模板（5 类）
│   └─ B-06 其他视觉物料（长图 / 人物卡 / 日程图 / 邀请函 / 数据成果图 / 简讯海报 / 社群通知图）
│
├─ 三、视频脚本类 Agent（C，1 个）
│   └─ C-01 短视频脚本（≤60 秒，招募 / 回顾 / 青年故事 / 科普 + 选题推荐 + 平台发布文案）
│
└─ 四、支撑角色（D，2 个，不产出内容）
    ├─ D-01 总编调度 Agent
    └─ D-02 质检 Agent
```

> 层级读法：**大类（内容类型）→ 子类（平台 / 物料族）→ 细分项（账号 / 具体物料）→ 一个细分项一个 Agent**。A-06~A-12 是「按内容目的」的跨平台体裁，不绑定账号；实际调用时由总编指定落到哪个平台账号的语气与排版。

## 六、共用层（第 0 节 · 所有 Agent 唯一维护源）

### 0.1 机构介绍（标准口径，所有账号通用）

宁夏青年发展公益慈善中心（品牌名：C公益），2013 年 6 月 16 日于宁夏银川发起成立，2016 年在宁夏民政厅登记成立，2023 年被认定为慈善组织，2024 年被评为 4A 社会组织，2025 年获得公开募捐资格。成立 13 年来，累计举办活动 620 余场，直接服务影响 6 万余人次西北青年。

> 说明：官网另有"链接全国数千个关注青年人成长与发展的组织和专家导师"一句，属补充描述，不强行塞进机构介绍固定段；需要时单独引用，不得改写数字。

### 0.2 品牌名硬规则

- 品牌名唯一正确写法 `C公益`：C 必须**大写**；C **前空一格**；C 与「公益」**之间不空格**；C 在行首或紧跟中文标点时不再加空格。
- 错误写法 ❌：`c公益`（未大写）、`C 公益`（C 与公益之间加空格）、`关注C公益`（C 前缺空格）。
- 官方唯二名称：`C公益` / `宁夏青年发展公益慈善中心（品牌名：C公益）`，禁只写机构名不露品牌、禁写成「（C公益）」。
- 「攒劲青年」对外全称，禁简称「攒劲」。
- 项目名官方写法（横杠用半角「-」、前后不加空格）：『青桥计划-对话吧』『青桥计划-疑惑当铺』『青桥计划-职业规划训练营』『探索者行动』。

### 0.3 共用禁区（所有类型通用）

- 禁说教命令式（你应该 / 必须）；禁过度营销促销腔；禁虚假煽情、编造经历 / 反馈 / 数据；禁成功学鸡汤、贩卖焦虑后兜售；不承诺"找到人生方向 / 改变命运"；数据只写官方公开口径，注明以当期官方信息为准。
- 避免词：一定、必须、绝对、彻底改变、逆袭、包过、保证、无敌、史上最、错过就完了、全网最、震惊体。
- 未定信息（免费、费用、人数、时间、截止、渠道、导师名单、地址、店铺名单）材料未写明不得自补，统一用占位：【斜体黄色｜待补充：XXX】。
- 原创，严禁抄袭；字体、图片、表情包、音乐须无版权授权，禁来源不明素材。
- 数字与前后中文之间加空格；全中文标点，引号用「」或『 』。

### 0.4 视觉品牌规范（所有 B 类 Agent 共用）

- **品牌色优先**：一切出图主色优先取品牌三色——**橙**（扎根西北）、**蓝**（连接资源与青年）、**绿**（向上生长）；中性底用米白 / 暖灰承托。禁高饱和荧光、禁紫粉电商风、禁与品牌色冲突的渐变。
- 色值一律取自可画「C公益」品牌工具箱，取不到则写【斜体黄色｜待补充：品牌色值】，**不得自拟十六进制**。
- LOGO：默认彩色版；海报用透明底带 ® 标版本，位置顶部居中 / 左上 / 右上；PPT 正文页右上角；线上账号头像用竖版；泛白底版仅用于报纸、广告单色印刷。
- LOGO 周边最小保护空间内不得出现任何文字、符号、图形；多 LOGO 横向排列，`C公益` 在前、合作方在后，间隔均匀，不得裁边。
- 字体：只用已授权可商用字体（默认思源黑体 / 思源宋体）；无法确认时标注「待人工确认字体授权」。
- 素材版权：实拍图须有授权；图标、贴纸、装饰元素一律授权可用。
- 留白与层级：主标题、副标题、关键信息、行动点、落款分区明确，不堆满。
- 画面文字同样受 0.3 约束：无结果承诺、无违禁词、无「报名即得 / 包就业 / 保 offer」。

### 0.5 事实与待补规则（所有类型通用）

- 文案、画面、字幕、口播里的每一条事实（时间、地点、人数、费用、截止、渠道、店铺、岗位、福利、数据、人物经历）必须来自素材；材料没写的留占位，不编造、不臆测"免费"。

## 七、编号、调用与边界规则

1. **编号固定**：A（文案）/ B（图文视觉）/ C（视频）/ D（支撑）。新增细分项只往后排号，不改旧号。
2. **一个细分项一个 Agent**：同一选题跨形态时不合并——例如「探索者行动」招募，会同时产生 A-05 推文、A-02 笔记、A-09 群话术、B-01 海报、C-01 短视频，**各自独立派单、独立编号、独立质检**。
3. **不跨号代写**：A-01~A-05 只写本账号文体；通用体裁 A-06~A-12 不套用账号专属规则（如店铺名照抄），需要时由总编把账号规则作为附加约束传入。
4. **视觉与视频以定稿为准**：B 类与 C-01 不新增事实，文字 / 字幕以已通过质检的文案为准；文案未定稿时，先出"待文案确认"版本。
5. **人工兜底项**：所有【待补充】、二维码、字体授权、实拍授权、Logo 源文件、人物授权，由人工在发布前补齐，Agent 不代填。
6. **本版仍不做的**：AI 直接剪辑成片、自动字幕上屏、数据看板、投放与效果追踪，需要工具链或平台权限，不在 Agent 职责内；C-01 只交付可拍摄 / 可剪辑的脚本与字幕文本。
7. **需求文档未列但已存在的账号**：抖音 / 视频号目前无独立账号 Agent，其文案由 C-01 承担；小红书与公众号账号如新增，按 A 类顺延编号新建，不改既有 Agent。
