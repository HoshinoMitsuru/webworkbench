## v4 规范层（第一顺位约束，依两份机构规范）

> 本节优先于本文其余任何表述；条款来源与判定方法见《00 品牌与文案规范落地手册》。

1. 品牌名唯一写法 `C公益`：C 大写、C 前空一格、C 与「公益」之间不空格；C 前紧跟中文标点或位于行首时不空格。禁 `c公益`、`C 公益`、`关注C公益`。
2. 官方唯二名称：`C公益` 或 `宁夏青年发展公益慈善中心（品牌名：C公益）`，禁只写机构名不露品牌。
3. 数字与前后中文之间加空格（数字在行首、或紧跟中文标点时不加）。
4. 全中文标点，引号用「」『 』；不加粗整段，重点加粗每篇 ≤3 处。
5. 未定内容写【斜体黄色｜待补充：XXX】，禁裸写【待补充】、禁编造。
6. 素材只用授权 / 可商用，文末逐行署名：`图片 | C公益 pexels` `音乐 | 周杰伦 - xxxx` `视频 | C公益` `文案 | XXX` `排版 | XXX`。
7. 标签品牌词 `#C公益`；微信单 # 后空一格，微博双 # 前后补空格。
8. 项目全称：青桥计划-对话吧 / 青桥计划-疑惑当铺 / 青桥计划-职业规划训练营 / 探索者行动（半角横杠、前后不加空格）。

**手册追加**：对接话术模板新增「规范自查三问」——品牌名写对了吗（C 前空格）、标签按平台规则了吗、图里的 LOGO 与色值合规范吗。

# 第一部分：流水线示范样例

## 样例 A · 文案线：一日职业体验双岗位招募（小红书 A-02）

> 样本：一日职业体验双岗位招募（古着搭配师 / 烘焙助手），目标 Agent = A-02 小红书攒劲青年（活动号），配套 B-01 正式招募版海报。

### 第 1 步 · 登记（D-01）

```
选题编号：20261127-01
选题名称：一日职业体验双岗位招募（古着搭配师 / 烘焙助手）
素材来源：用户提供招募稿（含两岗位任务与福利，时间/地点/人数/截止/渠道/费用未给）
内容类型：组合（文案 + 视觉）
子类：小红书 / 海报
目标 Agent：A-02（主）+ B-01（配套）
受众版本：不涉及
活动阶段：正式招募
文体或物料：活动笔记（职业体验招募）+ 3:4 正式招募版海报
目标平台：小红书 / 微信朋友圈转发
截止时间：【待补充】
待补信息清单：时间、地点、人数、报名截止、报名渠道、费用说明、二维码、字体与实拍授权
素材完整性：缺料（招募参数全缺，进入写作时一律占位）
状态：待分派
```

登记判定：素材缺招募参数，不影响写正文骨架，待补项进占位，可分派。

### 第 2 步 · 撰稿（A-02）

总编把「A-02 Prompt + 原始素材」喂给撰稿 Agent，收初稿。初稿（演示用，含两处故意留的问题）：

- 标题：📢 西北大学生看过来！两个宝藏岗位，解锁一日职业体验！
- 正文：痛点钩子 + 双岗位清单 + 行动召唤。
- 标签：#C公益 #一日职业体验 #大学生 #古着 #烘焙 #周末去哪儿（6 个；品牌标签 #C公益，C 与公益不空格）。

### 第 3 步 · 独立质检（D-02）

总编把成稿 + 编号「A-02」交质检 Agent，判定：

```
类型：文案
Agent：A-02 小红书攒劲青年

【通用 A】
A1 ✅  A2 ✅  A3 ❌  A4 ✅  A5 ✅
A6 ✅  A7 ✅  A8 ✅  A9 ✅  A10 ✅
A11 ✅  A12 ✅  A13 ✅

【专属 B5】
B5-1 ✅  B5-2 ✅  B5-3 ✅  B5-4 ❌
B5-5 ✅  B5-6 ✅  B5-7 ✅  B5-8 ❌

结论：打回

打回项：
- [A3 / B5-4] 位置标签「#C公益」：C 前缺空格 → 改「#C公益」。
- [B5-8] 位置标签仅 6 个 → 补到 8-11 个，且含 #C公益 #攒劲青年，兼顾品牌词与搜索词。
```

### 第 4 步 · 打回修改（A-02）

总编把打回项原样转回，重写标签段，不局部打补丁：

```
#C公益 #攒劲青年 #一日职业体验 #职业体验 #大学生 #西北 #古着搭配 #烘焙体验 #周末去哪儿 #公益招募
```

改完回质检复检。

### 第 5 步 · 复检 + 终审

复检：A3 ✅、B5-8 ✅，全绿。总编终审逐项核：

```
选题编号：20261127-01　Agent：A-02 小红书攒劲青年
事实一致 ✅（岗位任务/福利照素材，无编造）
待补填实 ⏳（时间/地点/人数/截止/渠道/费用待人工发布前补齐）
机构口径 ✅（本笔记未硬塞机构介绍，无自编数字）
品牌项目名 ✅（#C公益 空格正确）
配图版权 ✅（活动海报 + 授权实拍拼贴，不指定未授权照片）
排期渠道 ⏳（待人工填实）
结论：质检通过；待人工补齐待补项后放行。
```

### 第 6 步 · 视觉配套（B-01）

文案质检通过后，总编另起一张子卡（20261127-01-B），把定稿文字 + 品牌规范 + 授权素材交给 B-01，做 3:4 正式招募版海报：

- **喂**：定稿标题 / 岗位要点 / 待补项清单 + 品牌配色 + 已授权实拍或设计卡片素材 + 版本（正式招募版）。
- **回**：海报分区与逐字文案、底色主色、配图版权标注、可编辑性与高清导出说明、待人工确认项（二维码 / 字体授权 / Logo 源文件）。
- **质检**：交 D-02 走 C1-C10，核品牌名 Logo、配色、信息一致、待补占位、字体素材授权、3:4 规格、安全边距。
- **打回**：如画面把定稿没有的福利写上去（C3）、用了未授权字体（C5），原样转回 B-01 重做，复检到全绿。

### 第 7 步 · 发布 + 回流

- 发布：人工补齐待补项、确认二维码 / 授权 → 按排期发布；海报同步导出高清版。
- 回流记录：本篇仅标签空格与数量问题，属已覆盖规则，无新增；不产生新规则。

## 样例 B · 视频线：一场活动的 45 秒回顾短片（C-01）

> 样本：某期『青桥计划-职业规划训练营』结束后，用现场素材做一条 45 秒回顾短片，发视频号。
> 说明：本样例演示视频线的派单、出稿、打回、复检，重点看时长与授权。

### 第 1 步 · 登记（D-01）

```
选题编号：20261127-02
选题名称：职业规划训练营 · 45 秒回顾
素材来源：现场照片与视频片段（已授权）、环节时间线、3 位参与者采访原声（已签授权）、本次到场人数
内容类型：视频
子类：短视频
目标 Agent：C-01
活动阶段：结束（回顾）
文体或物料：回顾类 45 秒
时长：45s
目标平台：视频号（同步抖音）
待补信息清单：参与者姓名（化名确认）、BGM 曲库确认、字幕校对
素材完整性：基本齐全（缺 BGM 与化名确认）
状态：待分派
```

### 第 2 步 · 出稿（C-01）

C-01 交付（节选，演示用，故意留三处问题）：

- 主题：45 秒，讲"一群人花一天，重新想了一遍自己要做什么"。
- 结构：5s 钩子 + 10s 交代 + 20s 主体 + 10s 引导（总 45s）。
- 分镜：12 镜，其中第 3 镜 0-5s 为空镜（写"慢慢推进，营造氛围"）。
- 字幕：第 7 镜写「参加了这次，他彻底改变了自己的方向」。
- BGM：建议用「某流行歌曲片段，情绪温暖」。
- 发布包：视频号标题「职业规划训练营圆满成功，意义非凡！」。

### 第 3 步 · 独立质检（D-02）

```
类型：视频
Agent：C-01 短视频（回顾类）

【通用 A】
A1 ✅  A2 ✅  A3 ✅  A4 ✅  A5 ✅
A6 ❌  A7 ✅  A8 ❌  A9 ✅  A10 ✅
A11 ❌  A12 ❌  A13 ✅

【专属 E】
E1 ❌  E2 ✅  E3 ❌  E4 ❌  E5 ❌
E6 ✅  E7 ✅  E8 ❌  E9 ✅  E10 ✅

结论：打回

打回项：
- [E1] 第 3 镜 0-5s 为空镜且占满钩子位：前 3 秒无信息 → 改为具体画面 + 一句钩子，压到 3 秒内。
- [A6] 发布包标题「圆满成功，意义非凡」：套话且无据 → 改为客观事实型标题。
- [E3 / A11] 第 7 镜字幕「彻底改变了自己的方向」：夸大且违背当事人自述 → 改为"他说，至少知道自己下一步想试试什么"。
- [E4] BGM「某流行歌曲片段」：未授权 → 改用可商用曲库，标注曲库来源。
- [A8 / A12 / E5] 「彻底改变」属结果承诺与违禁词 → 全片排查同类表述。
```

### 第 4 步 · 打回重做（C-01）

- 第 1 镜改为：训练营现场全景 + 字幕「一天时间，重新想一遍自己要做什么」，3 秒内完成。
- 第 7 镜字幕按当事人原声改写，保留"还在试"的状态。
- BGM 换为可商用曲库条目，写明曲库名称与授权类型。
- 发布包标题改为「45 秒，看他们怎么重新想自己的方向」，简介补"活动信息以官方公告为准"。
- 其余镜号、时长、结构不动，总时长仍 45 秒。

### 第 5 步 · 复检 + 终审

复检：E1 / E3 / E4 / E5 / A6 / A8 / A11 / A12 全部 ✅。总编终审：

```
选题编号：20261127-02　Agent：C-01
时长 ✅（45 秒，前 3 秒有钩子）
事实 ✅（人数与环节按素材；参与者原声未改观点）
授权 ✅（人物授权、场地、素材、BGM 曲库）
字幕 ✅（每行 ≤14 字，无夸大）
发布包 ✅（视频号/抖音标题合规，话题含 #C公益）
待人工确认 ⏳（化名、字幕校对）
结论：质检通过；待人工确认化名与字幕校对后交拍摄剪辑。
```

### 第 6 步 · 交付成片环节

- C-01 交付的是脚本 + 分镜 + 字幕文本 + BGM 建议；拍摄、剪辑、上字幕由人工或剪辑工具执行。
- 成片完成后另走一次人工审片（事实、授权、字幕），不经 D-02（D-02 只审脚本）。

## 二、调用顺序（三条线）

```
D-01 登记（判类型 + 编号）
   ├─ 文案线：A-xx 交稿 → D-02（A + Bx/D）→ 打回 → A-xx 重写 → 复检 → 终审
   ├─ 视觉线：定稿 → B-xx 出稿 → D-02（A + C）→ 打回 → B-xx 重做 → 复检 → 终审
   └─ 视频线：素材 → C-01 出稿 → D-02（A + E）→ 打回 → C-01 重出 → 复检 → 终审
终审全绿 → 人工补待补 / 确认授权 → 发布 / 拍摄剪辑 → D-01 回流记录
```

组合件（如样例 A）按子卡拆开走线：文案先过，视觉后跟；两件各自质检、各自终审。

## 三、每步喂什么、回什么

### ① D-01 → 文案 Agent（A-01 ~ A-05 账号）
- **喂**：该账号 Prompt（整段）+ 原始素材（链接 / 附件 / 口述全文）+ 登记卡待补清单 + 落点要求（平台 / 版本 / 阶段）。
- **回**：标题 → 正文 → 标签 → 配图建议（按各账号输出顺序）。
- **不喂**：其他账号的红线、总编自己的判断。

### ①b D-01 → 通用体裁 Agent（A-06 ~ A-12）
- **喂**：该体裁 Prompt + 素材 + 落点账号的语气要求（如需按 A-02 语气写社群消息，附一句"落点语气参照 A-02，但不套用其店铺名规则"）+ 待补清单。
- **回**：按各自输出格式（A-06 两版 + 差异表；A-07 阶段文案；A-08 选题卡 + 来源表 + 主稿 + 改写；A-09 主备两版；A-10 三身份；A-11 通稿 + 简讯；A-12 口径表 + 正文）。
- **注意**：通用体裁不继承账号专属规则（如店铺名照抄），需要时由 D-01 显式附加。

### ①c D-01 → 视觉 Agent（B-01 ~ B-06）
- **喂**：质检通过的定稿文字 + 品牌规范 + 授权素材 + 物料类型与版本 / 张数 / 类别 + 待补清单 + 账号（B-02 需要）。
- **回**：分区与逐字文案、底色主色、配图版权标注、可编辑性、高清导出说明、待人工确认项（二维码 / 字体 / 实拍授权 / Logo 源文件）。
- **注意**：视觉 Agent 不自行新增事实，画面文字以定稿为准；未定稿标"待文案确认"。

### ①d D-01 → 视频 Agent（C-01）
- **喂**：素材（活动方案 / 访谈 / 科普主稿）+ 类型（招募 / 回顾 / 故事 / 科普）+ 目标平台 + 时长上限 + 素材清单（已有 / 待拍 / 待授权）+ 人物授权状态。
- **回**：主题 + 四段结构 + 分镜表 + 全片补充（画幅 / 字幕 / BGM）+ 素材清单 + 发布包 + 选题推荐 + 待补项。
- **注意**：脚本事实优先取自已通过质检的文案；视频不改文案事实。

### ② D-01 → 质检 Agent（D-02）
- **喂**：成稿 / 设计稿 / 脚本全文 + **类型**（文案 / 视觉 / 视频）+ **Agent 编号**。
- **回**：类型 + 编号 + A 段逐条 + 专属段（Bx / D / C / E）逐条 + 结论 + 打回项（条号 + 位置引用原文 + 问题 + 改法）。
- **注意**：总编不自己替质检下结论，也不删改打回条号；编号必须给，否则质检无法选专属段。

### ③ D-01 → 对应 Agent（打回转交）
- **喂**：打回项原样（条号 + 位置 + 原文 + 问题 + 改法），指明动作：文案「重写该段」/ 视觉「重做该分区」/ 视频「重出该镜」。
- **回**：改后整段 / 整稿，再交质检复检。
- **循环**：改完必回质检，直到全绿；不允许自判通过。

### ④ D-01 终审（质检全绿后）
- **核**：事实一致 / 待补填实 / 机构口径 / 品牌项目名 / 视觉规范 / 配图版权 / 视频授权与时长 / 排期渠道。
- **回**：选题编号 + 类型 + 逐项 ✅/❌ + 放行结论；不过则退回对应环节。

### ⑤ D-01 → 人工（补待补项 / 确认授权）
- **交**：所有【待补充】清单；视觉另交二维码、字体授权、实拍授权、Logo 源文件；视频另交人物授权、化名确认、BGM 曲库确认、政策来源。Agent 不代填、不编造。

### ⑥ 发布后 → D-01 回流
- **记录**：本次新踩问题；≥2 篇 / 2 件重复才提炼规则，人工确认后写进对应 Agent Prompt（账号层 / 通用体裁层 / 视觉层 / 视频层）；单次措辞留人工微调。

## 五、常见交接误区

- 撰稿自己审自己 → 必须独立质检。
- 总编替质检下「通过」→ 不行，以质检判定为准。
- 派单不带 Agent 编号 → 质检无法选专属段，必错。
- 打回只改一个字打补丁 → 要求重写该段 / 重做该分区 / 重出该镜。
- 待补项 Agent 自己编时间/费用/渠道 → 严禁，一律占位。
- 视觉 Agent 自行往画面加定稿没有的事实 / 福利 → 严禁，以定稿为准。
- 视频 Agent 把"目标"写成"已完成"、把参与者原声改成效果证明 → 严禁。
- 用 B-03 多图去替海报、或用 B-02 封面替整套多图 → 物料错配，按 3.2 路由表派单。
- 跨号搬规则（如把招募号店铺名规则塞进主号）→ 账号层不跨号。
- 通用体裁直接套账号专属规则（如 A-09 群消息照搬 B3-1 店铺名照抄）→ 需总编显式附加才生效。
