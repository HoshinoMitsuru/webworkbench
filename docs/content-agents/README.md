# C公益 内容生产 Agent 体系（v4）

本目录是机构「C公益 AI 内容生产」项目的 Agent 设计与规范文档，供工作台（`workbench/`）在生成内容时对齐口径。全部为可粘贴 Prompt、规则与测试样例，不含真实活动数据、真实人名与联系方式。

## 这是什么

按《C公益 AI 内容生产应用需求》的**内容类型**分类，拆成 19 个内容 Agent + 2 个支撑 Agent：

- 文案类 A-01~A-12：小红书 2 个账号（A-01 小C同学、A-02 攒劲青年）、公众号 3 个账号（A-03 主号、A-04 种草中心、A-05 攒劲青年）、通用体裁 7 个（三受众、活动阶段、科普、社群、朋友圈、新闻通稿、公益传播）
- 图文视觉类 B-01~B-06：海报、小红书封面、多图笔记、公众号封面与配图、PPT、其他物料
- 视频脚本类 C-01
- 支撑：D-01 总编调度、D-02 质检

所有 Prompt 以两份机构规范为第一顺位约束：《C公益文案撰写规范》《C公益品牌视觉对外露出使用规范》。

## 快速上手（按角色）

- **要写文案**：先读 `00` 的 A 段（文字规范），再到 `02` 找对应账号的 Prompt，整段复制贴进模型。
- **要做图/做海报**：先读 `00` 的 B 段（品牌色、LOGO），再到 `03` 取 B-01~B-06 对应 Prompt。
- **要拍短视频脚本**：取 `04` 的 C-01 Prompt，按分镜表填镜头。
- **要搭流水线/派单终审**：用 `06`（总编）派单，用 `07`（质检）逐条打回。
- **新人第一次接手**：先看 `08` 的三个走通样例和对接话术，再回头读 Prompt。
- **改完规则要验证**：用 `09` 的素材包和样题卡重跑一遍。

## 和工作台的关系

- 工作台生成公众号推文 / 小红书笔记 / 社群话术时，取 `02` 中对应账号的 Prompt 与 `00` 的 A 段（文字规范）。
- 生成 3:4 海报时，取 `03` 的 B-01 与 `00` 的 B 段（品牌色、LOGO 位置、保护空间）。
- 质检与打回逻辑参照 `07`；新增内容类型时按 `01` 的编号规则顺延。

## 使用约定

- 品牌名唯一写法 `C公益`（C 大写、C 前空一格、C 与「公益」之间不空格）。
- 文末署名格式：`图片 | C公益 pexels`、`音乐 | …`、`视频 | …`、`文案 | …`、`排版 | …`。
- 待补参数统一写【斜体黄色｜待补充：XXX】，不编造时间、地点、人数、费用、渠道。
- 本目录不含真实图片、名单、联系方式；测试稿中的人物均为化名或占位。
