## 一、结论摘要

1. **P0 主链路已闭环**：建活动 → 模板任务 → 资料 → AI 起草 → 提交/审核 → 发布记录 → 复制流程 → 资源监控，均可跑通；未登录拦截、审核前禁止发布、脱敏、相似文件提示均有效。
2. **两个 P0 验收缺口已补齐（2026-11-24）**：①任务详情新增“引用资料”勾选并持久化 `inputRefs`，生成按所选资料执行；②画布新增任务搜索，支持按标题/负责人/阶段定位并居中高亮。
3. **一个高优先合规风险**：“审核通过自动免标”与 2025-09-01 施行的《人工智能生成合成内容标识办法》存在解释风险；同时导出的 PNG 隐式元数据缺少内容编号、服务提供者、模型等要素。
4. **两个数据/资源治理缺口**：删除活动不清理磁盘文件；图片上传未强制监护人授权（A30）。
5. **外部可借鉴 14 项**，按“立即修 / 下一迭代 / 需决策”三档给出建议，均附来源，方便逐项拍板。

### 4.2 合规专项：AI 标识怎么改更稳

事实依据：
- 《人工智能生成合成内容标识办法》2025-09-01 施行，要求显式+隐式标识；第九条允许在“用户协议约定 + 日志留存不少于 6 个月”等条件下不添加显式标识；第十条要求用户发布时主动声明（[办法全文](https://www.gov.cn/zhengce/zhengceku/202503/content_7014286.htm)、[答记者问](https://www.cac.gov.cn/2025-03/14/c_1743654685896173.htm)）。
- 微信、抖音、DeepSeek 等平台已上线 AI 内容标识与提示机制（[光明网](https://m.gmw.cn/toutiao/2025-09/03/content_1304133959.htm)、[新华网](http://www2.xinhuanet.com/tech/20250909/fb164c6d092146aa8e13ddc283fe416a/c.html)、[人民网](http://politics.people.com.cn/n1/2025/1024/c458474-40588412.html)），微信公众平台也发布了专门公告（[微信开放社区](https://developers.weixin.qq.com/community/develop/doc/000ce4a4234cb8bee4c3d28436b009)）。

建议的落地方式（不推翻 PRD 的“人负责”原则）：
1. 保留“审核通过后对外可不显示 AI 字号”，但改称“机构确认免显式标注”，并记录确认人、时间、理由。
2. **隐式标识永远保留**：导出文件写入 `digitalSourceType`、服务提供者、模型名、内容编号、生成时间、活动/任务/版本 ID；即使正文去掉提示，元数据仍可追溯。
3. 发布记录增加“已在平台声明 AI 生成”勾选，未勾选时提示风险。
4. 涉及未成年人、受益人故事、敏感议题时，默认保留显式标识。
5. 首次使用时增加一页“AI 使用与标识说明”，作为第九条所需的协议提示；日志留存≥6 个月（现有 audit 已满足，补充导出/免标事件）。

### 第一批：立即修（不需外部依赖）

- G-16 自定义 AI 任务场景
- G-17 发布效果回填

### 第三批：需要你拍板（涉及外部依赖或投入）

- 飞书审批/通知（B-06）
- 违禁词库（自建或采购，B-07）

- 二维码现场收素材（B-10）

### 不建议做

- 自动发布到公众号/小红书：无稳定开放接口，封号与合规风险高。
- 复杂角色权限：PRD 已明确内测不分级，先靠流程与审核人字段约束。
- 自由连线式流程编排：当前固定 7 阶段更适合小团队，连线会显著增加理解成本。
- 全自动批量生成后直接发布：与“人工确认事实”的产品原则冲突。
