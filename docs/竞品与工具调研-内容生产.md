## 0. 先说清楚这份调研的边界

**我们一家都没有真正登录用过。** 本轮浏览器环境连续超时，Lovart、Canva、稿定、135、飞书均需登录，无法完成真实点击。因此：

- 所有"用户怎么操作"的步骤，均标注为 **【桌面推演】**——按官方文档和公开教程还原，不代表我们按过那个按钮。
- 价格标注为 **【第三方】** 的，是评测站口径，只能当量级参考，签约前必须看官网。
- 凡涉及"生成质量好不好"的判断，本文件**不给结论**，只给判断方法和一份 30 分钟自测脚本（第 8 节）。

> 这份文件的正确用法：不是"证明我们调研过"，而是**排除掉不该做的方向**，并让 11-20 的需求文档能说出一句有依据的话——"这一类工具我们看过，它们解决的是 X，不是 Y"。

**一句话结论**：

> 市面上的工具全部是**单点生成器**——要么生成图（Lovart、稿定、可画），要么生成排版（135、秀米），要么批量生成文本（飞书多维表格 AI）。**没有一个工具接受"一场活动的结构化记录"作为输入，并输出"公众号 + 小红书三类 + 海报"的成套内容。** 我们的缺口不在"再买一个设计工具"，而在**活动素材的结构化入口**和**事实锁定后的多平台改写**。

## 1. 为什么选这几个，不选别的

按"与本项目需求的重合度"排序，只保留 5 个：

| 工具 | 类型 | 为什么纳入 | 机构现状 |
|---|---|---|---|
| **Lovart** | AI 设计 Agent（无限画布） | 用户点名；代表"一句话出成套视觉"的最新形态 | 未使用 |
| **Canva 可画** | 在线设计 + Magic Studio | 机构招募公告里明确写"可画加分"；有公益免费通道 | **已在用/在用的人会** |
| **135 编辑器 / 秀米** | 公众号排版 | 机构排版岗的指定工具，是内容链的最后一公里 | **主力工具** |
| **稿定设计 AI** | 模板 + AI 海报 | 国内小红书封面/公众号首图最常用的替代品 | 未使用 |
| **飞书多维表格 AI 字段** | 结构化数据 + 批量生成 | 机构协作已在飞书；唯一"输入即结构化"的形态 | **已在用飞书** |

**主动排除**：即梦/美图设计室（只出图，和稿定高度重复）、剪映（短视频不在本次 MVP 范围，仅在结论里提一句）、各类"AI 写作 SaaS"（无法验证、且不解决排版与分发）。

## 2. 统一测试输入：一份活动简报

> 下面这份简报的**字段结构按真实活动设计**，具体内容除标注外均为 **示例占位**，用于测试工具"能不能吃下这种输入"。真实使用时由项目专员在活动结束当天填写。

```
【活动简报 · 示例】
活动名：一日职业体验 · 第 62 期｜走进「山屿」独立书店
项目线：攒劲青年 / 一日职业体验
合作空间：「山屿」独立书店（示例占位）
时间：2026-11-22（周六）14:00–18:00
地点：银川市金凤区（示例占位）
参与人数：12 名宁夏本地在校大学生（示例占位）
带队：项目专员 1 名 + 志愿者 2 名（示例占位）

三个现场细节（示例）：
1. 店主带大家拆一天的经营账：一本书从进货到上架，中间要经过几道手
2. 学员轮流做"15 分钟选书推荐"，要求用一句话说服陌生人
3. 一位学员说，她发现自己想做的其实是活动策划，不是书店店员

参与者原话（示例，发布前需本人同意）：
- "原来独立书店不是卖书，是卖选书的眼光。"
- "我第一次知道自己的专业可以这样用。"

可用素材：
- 照片 12 张（示例；其中 3 张已获本人同意可公开）
- 现场录音 8 分钟（未整理）

传播目标：
- 公众号：1 篇活动回顾（800–1200 字）
- 小红书：青年故事 1 条 / 活动反馈 1 条 / 公益科普 1 条
- 海报：回顾海报 1 张（3:4）+ 公众号首图 1 张（2.35:1）
```

**这份简报本身就已经暴露了第一个问题**：它不是任何工具的原生输入格式。Lovart 要的是设计 prompt，可画要的是模板 + 文案，135 要的是成稿正文，飞书要的是一行表格记录。**从"简报"到"工具输入"这一段翻译，现在没有工具替你做。**

## 3. 五个工具，各走一遍「输入—生成—修改—导出」

### 3.1 Lovart：AI 设计 Agent

**定位**【官方文档】：无限画布 + 多轮对话 + 局部重绘，一次生成多个方案，主打品牌视觉、海报、Logo、社交图。

**输入**【桌面推演】
1. 网页登录（官方站点在本环境抓取为空，实际入口需自行确认）。
2. 在左侧 prompt 面板写一段描述，选择风格预设（矢量 Logo / 霓虹海报 / 水彩插画等）和画幅（1:1 / 16:9 / 9:16）。
3. 上传现场照片作为参考图。
4. **关键动作**：把上面那份中文简报，"翻译"成一段面向模型的描述——活动名、要放哪几句话、什么风格、什么颜色、什么情绪。

> 这一步就是第一个手动环节。简报里"三个现场细节"不能直接贴进去，得由人决定"海报上只留哪一句"。**工具的输入门槛不是技术门槛，是判断门槛。**

**生成**【桌面推演】：点生成后，画布上一次出多张变体，可拖拽、分组、并排比较。适合"挑"，不适合"改"。

**修改**【第三方 + 桌面推演】
- 对话式改："把标题换成……""背景换成暖色"。
- 点选元素局部重绘，宣称支持文字与背景分离，可单独改文字。
- **但**：中文排版是这类模型的通病。第三方教程明确把"品牌名拼错/文字乱码"列为常见坑，解法是反复在 prompt 里强调"文字必须精确拼写"。也就是说，**中文字准不准，要靠人来盯，且不一定一次就对**。
- 版式的精确控制（字号差 2px、行距、对齐）做不到像素级，改一处常要重生成整块。

**导出**【第三方】：PNG / JPG / SVG / PDF（含印刷用 CMYK 口径），付费版含商用授权。**一次只能出一个尺寸**，3:4 海报和 2.35:1 首图要分别生成或分别裁。

**与本项目重合度**：只覆盖"海报"这一项，且不含海报文案的撰写。
**价格**【第三方，量级参考】：入门约 $9.9/月（250 积分），中档约 $40/月，高档约 $90/月；积分制，出图/出视频都消耗积分。
**结论**：它是"视觉生成器"，不是"内容生产线"。用它做一场活动的海报可以，做不了公众号长文、小红书三类文案、多平台适配。

### 3.2 Canva 可画：Magic Studio

**定位**【官方文档】：模板库 + 图层编辑器 + AI 套件（Magic Design 出初稿、Magic Write 写短文、素材生成器出图）。

**输入**【桌面推演】
1. 新建"小红书帖子"或"公众号封面"尺寸，或直接用 Magic Design 描述需求生成初稿。
2. 把简报里的文字粘进文本框，把照片拖进图框。
3. 若有品牌套件（Logo、主色、字体），可一键套用。

**生成**【官方文档 + 桌面推演】：Magic Design 按描述生成一版可编辑的设计；Magic Write 可在文本框内续写短文案。

**修改**：这是它相对 Lovart 的最大优势——**真正的图层编辑**，文字、图片、颜色都能精确改，不依赖模型重生成。缺点也在这里：**改得动，但都要人手动改**，AI 只负责第一版。

**导出**：PNG / JPG / PDF / PPT 等。**不能直接同步到公众号后台**，要下载再上传；小红书要自己按 3:4 导出。

**与本项目重合度**：覆盖"海报 + 首图 + 简单图文"，不覆盖长文写作与多平台改写。
**价格**【第三方 + 官方渠道】：个人免费版可用；**公益会员可通过腾讯技术公益渠道免费申请**（面向依法登记的基金会、慈善组织、志愿服务类社团/民非）。C公益 是 2023 年认定的慈善组织，**大概率符合申请条件**——这是本次调研里最直接可用的一条降本信息，但需机构自行提交审核。

> 注意：即使拿到公益会员，可画解决的仍然是"做图"，不是"写稿"。

### 3.3 135 编辑器 / 秀米：公众号排版

**定位**【官方文档】：公众号图文排版工具。135 已上线 AI 排版，官方页面写明支持"输入主题生成 / 导入文章排版"、30 秒极速排版、5000+ 可商用模板、"文字/图片/配色全可改"、一键同步到公众号。

**输入**【桌面推演】
1. 把已经写好的正文（Word / Markdown / 直接粘贴）导入。
2. 或只输入一个主题，让 AI 生成整篇 + 自动配图。
3. 选模板风格。

**生成**【官方文档】：AI 自动分段、套模板、配图、设置字号行距。

**修改**：模板内可改文字、换图、调配色；**但换模板等于全文重排**，改版式不是改样式，是换一套壳。

**导出/发布**：授权绑定公众号后，一键同步到后台草稿。**这是全场唯一真正打通"最后一公里"的工具**——它不只是导出文件，是把内容送进发布系统。

**与本项目重合度**：覆盖"排版 + 发布"，不覆盖"选题、写作、素材归档、多平台改写"。
**价格**【官方文档】：个人标准会员 ¥7.8/月起，高级 ¥20/月起，超级 ¥62/月起；AI 排版会员 ¥8/月起，年付 ¥109（每月 150 次 AI 排版、绑定 2 个公众号）。
**结论**：这不是竞品，是**必须对接的下游**。我们做的东西如果输出不能进 135/秀米，就等于多了一道工序，会被弃用。

> 秀米：官方首页仍以模板、H5、一键排版为主，**未见到官方 AI 排版入口**；部分第三方资料称其有 AI 版，属**【未知】**，需实测。

### 3.4 稿定设计 AI

**定位**【第三方】：一句话/一张图 → 匹配模板 → 生成海报与文案。模板覆盖小红书封面、公众号首图、节日海报等。

**输入**：输入一句需求，或上传一张活动照片，选场景（小红书封面 / 公众号首图）。
**生成**：自动匹配模板、填文案、合成图。
**修改**：在线编辑，另带 AI 抠图、消除、扩图、高清修复。
**导出**：JPG / PNG，多尺寸。

**与本项目重合度**：和可画高度重叠，优势是国内模板更贴小红书审美，劣势是品牌一致性弱、免费版有水印与限制。
**价格**【第三方，量级参考】：约 ¥40/月，年付约 ¥347。

**结论**：如果机构已有可画且能拿到公益会员，**没有理由再买稿定**。两者选一个即可。

### 3.5 飞书多维表格 AI 字段

**定位**【官方文档】：在表格里配置"AI 字段"，对整列批量调用大模型，按指定结构输出；支持自动更新（字段变化即重算）、支持在工作流/自动化里"AI 生成文本"。

**输入**【桌面推演】
1. 建一张表：活动名 / 项目线 / 时间 / 人数 / 三个细节 / 参与者原话 / 授权状态 / 照片链接。
2. 新增"AI 字段"，写指令（例如"根据本行信息，写一条 300 字小红书青年故事，语气温暖、不用感叹号"）。
3. 点"生成全列"。

**生成**：整列一次性生成，**这是唯一能"批量处理一场接一场"的形态**——27 场活动就是 27 行，不是 27 次对话。

**修改**：改单元格 → 自动更新重算。**官方文档明确警告：重算会覆盖原内容且无法恢复**，所以必须留一列"人工定稿"做副本。

**导出**：表格、文档、通过自动化推送到群/文档；**不能出图**，也不能直接排版。

**与本项目重合度**：覆盖"输入结构化 + 批量文本生成"，**不覆盖**排版、出图、发布。
**价格**【官方文档】：AI 功能每月有免费额度，超出后走企业购买的额度。

**结论**：它是最接近我们 MVP 数据底座的现成工具。**如果只选一个"底座"，应该选它，而不是自建后台。**

## 4. 四段链路横向对比

| 环节 | Lovart | 可画 | 135/秀米 | 稿定 | 飞书多维表格 |
|---|---|---|---|---|---|
| **输入** | 手写设计 prompt | 模板 + 粘贴文案 | 已成稿正文 / 一个主题 | 一句话 / 一张图 | **一行结构化记录** |
| **能否直接吃"活动简报"** | 否，要人翻译成 prompt | 否，要人拆成文案+图 | 否，要人先写成稿 | 否，要人给一句话 | **接近，需先建表** |
| **生成** | 多张视觉变体 | 一版可编辑设计 | 整篇排版 | 海报+文案 | **整列批量文本** |
| **修改粒度** | 对话/局部重绘，不精确 | **图层级，精确** | 模板内可改，换版式=重排 | 图层级 | 改单元格重算 |
| **导出** | PNG/JPG/SVG/PDF | PNG/JPG/PDF/PPT | **一键同步公众号** | JPG/PNG | 表格/文档，**不能出图** |
| **多平台适配** | 手动逐个尺寸 | 手动逐个尺寸 | 只服务公众号 | 手动逐个尺寸 | 不分平台，只出文本 |
| **价格量级** | $10–90/月 | 免费 / 公益会员免费 | ¥8–62/月 | ~¥40/月 | 免费额度 + 企业额度 |
| **与本项目重合** | 海报（不含文案） | 图 + 首图 | 排版 + 发布 | 图 + 文案 | 结构化 + 批量文本 |

## 5. 能力重合矩阵：对照我们的五类输出

| 我们想要的输出 | Lovart | 可画 | 135/秀米 | 稿定 | 飞书 |
|---|---|---|---|---|---|
| 公众号活动回顾长文 | ✗ | ✗ | 排版✓ / 写作✗ | ✗ | 文本✓（需人调） |
| 小红书·青年故事 | ✗ | ✗ | ✗ | 部分（模板文案） | ✓（批量） |
| 小红书·活动反馈 | ✗ | 图✓ / 文案✗ | ✗ | 图✓ / 文案✗ | ✓（批量） |
| 小红书·公益科普 | ✗ | ✗ | ✗ | ✗ | ✓（批量） |
| 海报文案 | ✗（只出图） | ✗ | ✗ | 部分 | ✓ |
| 海报画面 | ✓ | ✓ | ✗ | ✓ | ✗ |
| 多平台一稿多版 | ✗ | ✗ | ✗ | ✗ | 部分（多字段） |
| 素材"是否可公开"管控 | ✗ | ✗ | ✗ | ✗ | ✓（字段可控） |

**读法**：没有任何一列是满的。**唯一横跨"文本 + 批量 + 授权字段"的是飞书；唯一打通"发布"的是 135。** 这两者之间的空白，就是我们的位置。

## 6. 所有工具都做不了、必须人来的环节

按发生顺序列，这一节直接对应需求文档里的"边界说明"。

| # | 手动环节 | 为什么工具做不了 | 谁来做 |
|---|---|---|---|
| M1 | **把活动变成一行结构化记录** | 工具不参与活动，没人填就没有输入 | 项目专员，活动当天 5 分钟 |
| M2 | **判断哪 3 个细节值得写** | 需要现场感和编辑判断 | 带队人 / 文案 |
| M3 | **事实核对**（人数、期数、金额、备案号、合作方全称） | 模型会编，且机构口径不统一（600 场 vs 620 场） | 文案 + 项目专员 |
| M4 | **授权确认**（照片、姓名、学校、原话） | 工具没有授权状态，只能人标 | 项目专员 |
| M5 | **调性把关**（朋辈、温暖、不居高临下） | 通用模型默认"宣传腔" | 文案 |
| M6 | **平台语法适配**（小红书标题字数、话题标签、封面 3:4、公众号首图 2.35:1） | 每个工具只管自己那一段 | 排版 / 小红书岗 |
| M7 | **排版落地** | 生成的是文本，不是可发布图文 | 135/秀米 |
| M8 | **发布、定时、数据回收** | 除 135 同步公众号外，均需人工 | 运营 |

**结论**：工具能替掉的是"从结构化信息到第一版文字/图"这一段（M6 之前的一半）。**M1–M5 全部在人这边，而它们恰好是最耗时的部分。** 这也解释了为什么"再买一个工具"不会让产能翻倍。

## 7. 三条结论（写给需求文档）

**结论一：市面工具解决"生成"，我们的问题在"生成之前"。**
五个工具都需要人先把简报翻译成各自的输入格式。真实痛点是 P3（素材找不到）和 P9（素材只用一次）——**素材根本没被结构化，工具再强也没有原料**。所以 MVP 的第一优先级是"活动结束当天填一行"，不是"接一个更强的模型"。

**结论二：不自建画布、不自建编辑器、不自建模板库。**
Lovart 和可画的护城河是画布与模板，我们四周做不出来，做出来也没人用。正确的分工是：**飞书多维表格做底座 → 大模型做改写 → 135/秀米做排版 → 可画（公益会员）做出图**。我们只做中间那段"别人没有的"：活动字段 → 多平台版本 + 事实锁定。

**结论三：能被验证的价值只有两个数。**
一是"一场活动从有素材到三平台可发布，耗时从几天降到几小时"；二是"27 场活动里，实际发出内容的场次占比"。如果四周后这两个数没动，方案就是失败的——**不要用"生成了多少字"来验收**。

## 8. 30 分钟自测脚本（有账号时照做）

目的：把本文件的【桌面推演】升级为实测。全程用第 2 节那份简报，**只记录三个数：耗时、必须人工修改的次数、能否直接发布**。

| 时间 | 动作 | 记录什么 |
|---|---|---|
| 0–5 min | 打开简报，准备好 3 张已授权照片 | 简报是否够用；缺哪些字段 |
| 5–12 min | **Lovart**：把简报写成一段 prompt，生成 3:4 海报；选一张改一处文字；导出 PNG | 中文有没有错字/乱码；改文字成功几次；导出尺寸是否够 |
| 12–18 min | **可画**：用品牌色做一张小红书封面，套简报里的一句话 | 从空白到可用几分钟；中文字体是否够；导出是否 3:4 |
| 18–24 min | **135**：把 800 字回顾稿粘进去，AI 排版，尝试同步到草稿箱 | 排版后手工调了几处；同步是否成功；手机预览是否错位 |
| 24–30 min | **飞书**：建 8 列表，填这一行，配 3 个 AI 字段（长文/故事/科普），生成 | 三个版本能否直接改；重算是否覆盖；一条耗时多少 |
| 收尾 | 把三次"必须人工改"的点记成清单 | 这份清单就是需求文档的"手动环节"章节 |

**红线**：如果某个工具在 7 分钟内没能产出"可以直接粘贴"的东西，它就不适合放进机构的工作流——**志愿者每周只有 8–15 小时**。
